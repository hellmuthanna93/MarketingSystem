# Client emails — Anna Hellmuth

Lifecycle emails in Anna's voice: warm, brief, grounded, never pushy. Read `practice-voice` and `practice-profile` first. Full template set: `business-site/docs/09-toolkit/05-client-emails.md`.

## Principles

- Short. Respect the reader's time and intelligence.
- One purpose per email.
- Soft CTA only; adults decide for themselves.
- Use `{{placeholder}}` for personalization.
- Multilingual: keep warmth and clarity; adapt idioms for DE / UK / RU.

## Template set

| Template | Purpose | CTA |
|----------|---------|-----|
| Intake confirmation | After discovery call booked | Calendar details + what to expect |
| Pre-session reminder | 24h before | Link + gentle "nothing to prepare" |
| Post-session check-in | After first session | Reflection prompt; optional |
| Package renewal | Near end of a package | Invitation to continue, no pressure |
| No-show / missed | Respectful re-invite | Reschedule link |
| Testimonial ask | After meaningful progress | Anonymous, opt-in, easy to decline |
| Wedge → package follow-up | Day 7 after Clarity Session | Invite package conversation |

## Voice reminders

- No urgency, no "limited spots", no guilt.
- Name the human moment ("I imagine this past week held a lot") before logistics.
- Sign off simply: *Warmly, Anna* (EN) / *Herzlich, Anna* (DE).

## Confidentiality

Never reference clinical detail in a way that could identify the client. Testimonials are anonymous and opt-in only (see `case-studies-anonymized`).
