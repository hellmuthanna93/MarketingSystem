# Wedge: Clarity Session — Anna Hellmuth

**Status: TBD / proposed.** Name, price, and exact promise are not final. Do not publish client-facing wedge copy until Anna confirms. See `practice-profile` for the canonical status.

A productized, low-commitment way to experience Anna's core strength — naming the pattern precisely, with warmth and grounded certainty — without committing to a full package. Distinct from the free discovery call (which stays a fit check).

Read `practice-voice` and `practice-profile` first. Full spec: `business-site/docs/03-offerings/02-wedge-offer-clarity-session.md`.

## Shape (proposed)

- **Format:** Single 90-minute online session + written pattern summary (1–2 pages) within 72 hours
- **Price:** €250–€300 (TBD)
- **Promise:** Leave with a clear map of the pattern keeping you stuck — and the next step forward — without committing to a full package
- **Lane:** works for both counseling and coaching prospects; the summary names which lane fits

## Conversion mechanic

```
Free discovery call (or inbound) → Clarity Session (paid wedge) → day-7 follow-up → package
```

The wedge is the bridge for people who want to feel the depth before committing to 6–12 sessions.

## Delivery SOP (repeat every time)

1. **Pre-session intake** — send short intake form (current situation, what feels stuck, what they've tried, what they want)
2. **90-minute session** — recognition → name the pattern → what keeps it locked → where it shows up → possible next step
3. **Draft written summary** within 48h
4. **Review & send** within 72h of session
5. **Day-7 follow-up email** inviting a package conversation (no pressure)

## Written summary structure (deliverable)

The summary template lives at `business-site/docs/09-toolkit/06-wedge-deliverable-template.md`. Sections:

1. **The pattern we named** — the core inner loop, in plain language
2. **What keeps it locked** — the protective logic underneath
3. **Where it shows up** — concrete life areas (work, relationships, body, decisions)
4. **The next step** — recommended path: counseling package / coaching package / specific focus / referral

## Starter checklist (run for each wedge client)

- [ ] Intake form sent and returned
- [ ] Calendar slot booked, Zoom link sent
- [ ] Session held; notes captured
- [ ] Summary drafted (voice: `practice-voice`)
- [ ] Summary reviewed and sent within 72h
- [ ] Day-7 follow-up scheduled

## Voice for the summary

Warm, precise, grounded. Name the pattern so the client feels seen. End with possibility and a clear, pressure-free next step — never a hard sell.
