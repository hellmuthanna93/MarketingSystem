# Logo & Mark

> The logo already exists and is in use across the site, social, and directory listings. No concept exploration is needed; this doc documents usage.

## Current mark

- Wordmark/logo file: `Website/anna-hellmuth/assets/images/logo.png`
- Favicon: `Website/anna-hellmuth/assets/images/favicon.ico`
- Used in: site header/footer, this suite's dashboard, blog, and the Marketing Center hub

## Usage rules

- Place on burgundy or cream backgrounds with clear space around it
- Maintain aspect ratio; do not stretch or recolor
- On burgundy sections, use the version that reads on dark; on cream, the standard version
- Pair with Source Serif 4 in any lockup
- Keep the directory badge (Location Independent Therapists) only in the website footer context, not as a logo substitute

## Don'ts

- Don't recreate the logo in HTML/CSS or invent new marks
- Don't apply effects (shadows, gradients) that aren't in the source asset
- Don't use off-brand colors behind it

## So what

The visual identity is settled — the logo is an asset to place correctly, not redesign. For all other visual rules, see [03-visual-identity.md](03-visual-identity.md) and [brand/DESIGN.md](../../../brand/DESIGN.md).
