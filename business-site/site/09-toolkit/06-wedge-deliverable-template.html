Clarity Session — Written Summary Template

The deliverable that makes the wedge worth its price: a 1–2 page written map sent within 72 hours of the session. Warm, precise, ends on a clear next step. Voice per practice-voice; methodology per the wedge-clarity-session skill.

Replace {{placeholders}}. Keep it to 1–2 pages. No client-identifying detail beyond the client's own copy. Wedge is TBD until confirmed.

Template

Clarity Session summary for {{name}}
{{date}} · Prepared by Anna Hellmuth

Dear {{name}},

Thank you for the openness you brought to our session. Here's the map of what we found together — something to return to as you sit with it.

The pattern we named

{{Describe the core inner loop in plain, precise language the client will recognize. One short paragraph. Name it the way they'll feel seen — e.g. "On the outside you keep everything functioning; on the inside there's a constant bracing, as if rest has to be earned and never quite is."}}

What keeps it locked

{{The protective logic underneath — why this pattern made sense, what it has been protecting. Compassionate, not clinical. e.g. "This isn't a flaw. It's a strategy that once kept you safe — and it's been running long after the danger passed."}}

Where it shows up

{{2–4 concrete life areas, as the client described them.}}

  • Work: {{...}}
  • Relationships: {{...}}
  • Body / energy: {{...}}
  • Decisions: {{...}}

The next step

{{One clear, honest recommendation — counseling package / coaching package / a specific focus / a referral. Frame as possibility, not pressure.}}

If you'd like to keep going, the natural path from here would be {{recommendation}}. And if you'd rather sit with this for a while first, that's completely valid — the map will still be here.

Whatever you choose, I'm glad we did this work.

Warmly,
Anna

Quality bar (before sending)

  • [ ] The pattern is named precisely enough that they'll feel seen
  • [ ] The "what keeps it locked" section is compassionate, not pathologizing
  • [ ] Concrete, in their own life terms — not generic
  • [ ] One clear next step, framed as possibility
  • [ ] Anna's voice; humanizer pass done
  • [ ] 1–2 pages; sent within 72h
  • [ ] No outcome promised; no identifying detail mishandled

So what

This template makes the wedge deliverable consistent and high-value — the conversion asset that turns a single session into a package decision, without a hard sell. Pairs with the day-7 follow-up email (05-client-emails.md #8).
