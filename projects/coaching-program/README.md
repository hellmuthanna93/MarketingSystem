# Coaching Program

Working space for developing Anna Hellmuth's new, specific, sellable coaching
program.

## Start here

Read [CONTEXT.md](CONTEXT.md) before creating strategy, copy, design, or delivery
materials. It separates confirmed practice facts from decisions that still need
to be made.

## Repository rules

- Use `brand/` as the source of truth for voice, visual design, and marketing.
- Use `.cursor/skills/practice-profile/` before stating prices, credentials,
  services, or claims.
- Mark unknowns `TBD`; do not turn proposals into confirmed facts.
- If HTML or other visual assets are added here, import the shared CSS from
  `../../brand/`. Never hardcode brand colors.
