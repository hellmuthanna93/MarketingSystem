# Graphics & print

One-pagers, handouts, and PDF exports as static HTML using the shared brand layer.

**Workflow:**

1. Create an HTML file that links `../../brand/*.css`.
2. Set page size in CSS (`@page` for print) per [`brand/layouts.md`](../../brand/layouts.md).
3. Print → Save as PDF at 100% scale.

For Figma/Canva, copy values from [`styleguide/index.html`](../styleguide/index.html) or [`brand/tokens.reference.json`](../../brand/tokens.reference.json).
