# Social media templates

Future HTML templates at fixed sizes (1080×1080, 1080×1920, etc.).

**Before building:**

1. Link styles from `../../brand/` (see root README).
2. Read [`brand/layouts.md`](../../brand/layouts.md) for dimensions and safe zones.
3. Use [`brand/voice.md`](../../brand/voice.md) for CTAs.

Export finished frames via browser screenshot or Print to PDF at exact pixel dimensions.
